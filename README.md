# Tabletop Kit - Soundboard

Play crossfading ambient tracks and layered sound effects from a configurable sidebar deck in Obsidian.

## Features
- **Exclusive Atmosphere Playback:** Automatically loops ambient audio and smoothly crossfades (simultaneously or sequentially) when switching tracks.
- **Polyphonic Layered SFX:** Trigger overlapping one-shot sound effects over your active atmosphere, or toggle individual SFX tracks to loop.
- **Per-Track Controls:** Adjust individual track volume, toggle loop mode inline, and assign custom TTRPG icons to any audio file.
- **Sidebar & Main Pane Ready:** Switch between compact **Tiles** and **List** views, filter by category (**All**, **Atmosphere**, **SFX**), and control overall levels with a **Master Volume** slider.

## Setup
1. Open **Settings → Tabletop Kit - Soundboard**.
2. Select your **Atmosphere Folder Path** and **SFX Folder Path**.
3. Configure your preferred fade-in/fade-out durations and crossfade mode.
4. Click the speaker ribbon icon (or run **Open Soundboard** from the Command Palette).
